# MinhaGeladeira

MinhaGeladeira é uma aplicação Java desenvolvida como projeto de estudos para praticar Programação Orientada a Objetos (POO), JDBC e MySQL. O sistema permite gerenciar produtos, categorias, receitas e estoque, descontando automaticamente os ingredientes utilizados sempre que uma receita é preparada.

## Tecnologias

- Java
- MySQL
- JDBC
- Git
- IntelliJ IDEA

## Conceitos aplicados

- Programação Orientada a Objetos (POO)
- DAO (Data Access Object)
- Persistência de dados
- Modelagem de Banco de Dados Relacional
- CRUD
- Relacionamentos entre tabelas
- Separação de responsabilidades (Model, DAO)
